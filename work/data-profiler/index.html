What it is

Two plug-and-play scripts that read one data file and write a Markdown profile of it: structure, types, labels, value ranges, missingness and quirks. The profile is a handoff document, so an analysis script can be designed from it alone. The confidential mode auto-detects identifier columns and never prints one of their values.

What it changes

  • Design the analysis from the profile, without needing the data in the room
  • Sensitive columns are detected automatically, not remembered by the analyst
  • Same profile format across SPSS, Excel and CSV inputs
