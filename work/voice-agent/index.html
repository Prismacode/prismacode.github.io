What it is

A standalone voice interface over the same workspace: a three-tier intent router that recognises anchored commands before it ever guesses, dictation straight into a live terminal, and a destructive-command check that requires a spoken or typed confirmation. The mode toggle is the design centrepiece - in silent mode the voice process is killed, not muted, so a shared office can verify it in the task manager.

What it changes

  • No fuzzy execution: an unrecognised command suggests, it never runs
  • Silent mode is verifiable rather than promised
  • Speech and text both flow through one route function, so behaviour cannot diverge
