What it is

A folder, versioning, transfer and publication-readiness standard for recurring statistical products. Every product is entered through a single state file that states current status, next action and where the current version lives - so a colleague, a successor, or the same person six months later does not have to reconstruct context from filenames.

What it changes

  • One file to read before touching a product, instead of guessing from folders
  • Transfers carry checksums and a log, so a stale copy is detectable
  • Handover becomes a packet, not a conversation you have to be present for
