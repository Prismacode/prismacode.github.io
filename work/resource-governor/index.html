What it is

A scanner and advisor for a Windows machine: processes, startup items and services, matched against a catalogue of known components and turned into recommendations that state the trade-off rather than telling you to disable things. Version one has no actuator file at all, and a test harness hashes the machine before and after each scan to prove nothing was touched.

What it changes

  • Recommendations name the cost of taking them, not just the benefit
  • Read-only is proved by a hash comparison, not asserted in a README
  • An unknown component is investigated, never disabled on a guess
