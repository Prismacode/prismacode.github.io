What it is

Instructions, standing rules and reusable skills live in one canonical source. A build step compiles that source into the configuration file each runtime expects - and refuses to ship if the source has drifted, if a heading no longer matches, if the encoding would mangle Spanish characters, or if a vendor's name leaked into text meant to be portable.

What it changes

  • One edit propagates to every AI tool you use, instead of four divergent copies
  • Vendor lock-in becomes a build target rather than a rewrite
  • Hand-edited generated files are detected and archived, so drift cannot go quiet
