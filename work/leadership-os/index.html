What it is

A build specification for the failure mode where the strongest executor absorbs everyone else's work: accountability never forms, the team never develops, and it looks like success from above. The design answers it with a commitment ledger, a tripwire at the moment of absorption, a written rule for coach-versus-escalate, and a weekly rhythm short enough to survive a busy week. It is published here as architecture, not as a running system.

What it changes

  • Names the load-bearing adoption risk in the spec instead of discovering it later
  • Every stored note must be an observable fact the named person could read
  • Personnel-adjacent data never leaves the machine, by design
